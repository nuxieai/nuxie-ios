Generated by the parent repository's `tools/sdk-fixtures/generate-purchase-scope-fixture.mjs` through the production publisher WASM. `snapshot.json` is the exact authored input; `provenance.json` binds input, generator, WASM and output hashes.

The `Purchase` screen uses `PurchaseRoot` / `purchase.root`. Its `first` and `second` properties reference distinct `Plan` instances (`plan.first` and `plan.second`) with placement values `plan:monthly` and `plan:annual`. Both render instances of the same `Plan card` component. The root has its own `root:yearly` placement to detect incorrect root fallback.

This fixture establishes a real published graph for native instance-scope tests. It does not yet include a signed Journey wrapper or establish pointer-to-checkout behavior. Those remain required qualification steps.
