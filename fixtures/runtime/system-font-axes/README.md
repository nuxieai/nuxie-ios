# System font rendering fixtures

Generated by the native `editor-publisher-wasm` Rust example
`system_font_fixture` in the Nuxie publisher repository. `provenance.json`
records the publisher and runtime source commits, generator source/binary
hashes, private reference digest, and scene declarations/hashes. The actual
runtime source commit is recorded separately because it precedes parent pin
adoption. No private System font bytes are included.

The regular/bold scenes preserve production `wght` and automatic `opsz` records.
The optical baseline reserializes the regular scene; its control changes only
`opsz` from 32 to 17 while authored size remains 32. CoreText independently
confirms different outlines for these coordinates on the extracted device face.

The mixed scene contains a System text row and a CDN row using the existing
redistributable Roboto subset (`mixed-cdn.ttf`, which contains the glyph `a`).
The publisher emits only this CDN font payload. Its Journey wrapper in the
acquisition test is test-signed; it does not claim full release-publisher
qualification.

The four acquisition/rendering tests passed on iOS 26.5 in
`Test-NuxieSDKUnitTests-2026.09.17_12-53-35--0700.xcresult`. Regeneration after
committing the generator and publisher source reproduced every scene, snapshot,
and CDN payload byte exactly. Runtime hardening adoption and System capability
activation are separate release requirements.
