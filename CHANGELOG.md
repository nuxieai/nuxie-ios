# Changelog

## 0.1.1

Updates the embedded runtime to [apple-runtime-v0.10.17](https://github.com/nuxieai/nuxie-runtime/releases/tag/apple-runtime-v0.10.17).

- Improves Experience layout when content resizes, scrolls, or changes visibility.
- Improves CSS box painting, rounded clipping, borders, and pointer handling.
- Adds text underlines and strikethroughs, including updates while an Experience runs.
- Fixes frame writes when a component-list row has been removed.

Update the SDK dependency to 0.1.1; no host-app API changes are required.
